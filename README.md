# Book inventory

Personal book giveaway inventory, published at https://pjocke.github.io/book-inventory/.

Edit `index.html` to update the inventory. Keep books in their category and mark unavailable books with strikethrough and a Keeping, Keeping for now, or Given away tag. Update the category and overall totals when changing availability.

GitHub Pages publishes from the root of the `main` branch. No build tools are required.
